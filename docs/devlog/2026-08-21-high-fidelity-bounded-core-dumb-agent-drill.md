# 2026-08-21 — High-Fidelity Bounded Core Dumb-Agent Drill

## Purpose

This is a same-model **artificial-ignorance** drill, not an independent fresh-model audit.

The goal is to tune the continuity balance after two opposite failure modes were observed:

1. a truly fresh Agent stayed on stale `main` because no discoverable default-branch bootstrap pointer existed;
2. an aggressively shortened Strategy Core risked preserving slogans while losing the causal logic behind the mission.

The test asks whether the normal bounded bootstrap now contains the **minimum sufficient context**: enough to reconstruct the founding mission in depth, but not enough to become a growing archive of old industries and Agent history.

## Restricted test inputs

For this drill, pretend all old chat and old industry history is unavailable. The allowed conceptual bootstrap is only:

1. `FRESH_AGENT_BOOTSTRAP.md` — cold-start routing;
2. `STRATEGIC_COMPASS.md` — long-term mission and why;
3. `METHODOLOGY_CORE.md` — cross-industry method and why;
4. `.longcycle/handoff/current.json` — medium/short horizon and active context;
5. `CONTINUE_HERE.md` — execution bootstrap/live refresh discipline.

Explicitly excluded from the reconstruction step:

- all old devlogs;
- previous strategic/fresh-agent audit reports;
- completed industry packages;
- raw Memory Leads;
- old chat summaries;
- full repository archaeology.

## Test 2 — mission semantic fidelity

The Agent must explain the mission in its own words, not quote headings.

### F1 — founding problem

Recovered: the project begins from the belief that preserving the key, true history of an industry across long time horizons creates value because long, comparable history can expose risk/opportunity without requiring sophisticated black-box prediction.

**PASS**

### F2 — final facts are insufficient

Recovered: a database of what eventually happened creates hindsight. It does not tell us what a rational participant could know or believe at the time.

**PASS**

### F3 — contemporaneous cognition is first class

Recovered: Expectations/Judgments, their reasons, conditions, risks and revisions must be preserved separately from later Reality/Outcome because historical decision quality can only be evaluated from the contemporaneous information set.

**PASS**

### F4 — make the future unknown again

Recovered: historical replay must transform an already-known outcome back into a future that was still uncertain at the historical date.

**PASS**

### F5 — point-in-time / no-lookahead

Recovered: later-published information cannot leak backward; otherwise the product is a hindsight database rather than industrial memory.

**PASS**

### F6 — why history itself can be analysis

Recovered: when evidence is real, semantics comparable, revisions/failures retained and the time span is long enough, repeated feedback between investment, supply, inventory, margins, technology and demand becomes visible through ordinary causal reasoning/common sense.

**PASS**

### F7 — model/search vs evidence

Recovered from Strategy + Method Core: AI/model memory and search are discovery instruments; they help find missing history, but original evidence and claim-scoped authority determine publishable historical knowledge.

**PASS**

### F8 — trajectories matter

Recovered: delays, withdrawals, restarts, wrong forecasts and revisions are part of history and must not be overwritten by final actual values.

**PASS**

### F9 — cross-industry destination

Recovered: each industry is a proving environment. The final system must preserve and replay industrial cognition across industries; old industry facts should not become permanent Agent startup memory.

**PASS**

### F10 — means vs ends

Recovered: database, crawler, RAG, Agents, Memory Atlas, CI, handoff, schema and reports are tools. If they improve while evidence-backed point-in-time replay does not, the project is drifting.

**PASS**

### Mission result

**10/10 semantic facets recovered without old chat/devlog.**

The longer Strategy Core materially improves reconstruction versus a slogan-only core because it explains the causal chain from historical preservation → contemporaneous cognition → no-lookahead replay → cross-cycle common-sense analysis.

## Test 3 — stable methodology reconstruction

Recovered from `METHODOLOGY_CORE.md` without industry history:

1. historical Memory-first, Evidence-final;
2. current Source-first, Archive-now;
3. Memory Lead is discovery, never Evidence; `not_found != false`;
4. claim-scoped authority and independent evidence clusters;
5. point-in-time/no-lookahead time semantics;
6. semantic comparability before aggregation/corroboration;
7. preserve revision/state trajectories rather than final answers only;
8. high-capability model discovers/structures; lower-capability Agents execute claim-scoped evidence search;
9. abstractions are pulled by real benchmarks rather than speculative platform design;
10. stronger model vintages create new immutable recall vintages and backfill diffs;
11. multi-Agent continuity uses bounded cores + dynamic handoff + replaceable active context;
12. continuity optimizes semantic fidelity + context economy + bounded growth, not minimal text size.

**Result: 12/12 PASS.**

## Test 4 — horizon reconstruction

Using only `current.json` for dynamic intent:

- **Medium term:** prove the first real benchmark end-to-end with archived original evidence supporting no-lookahead Reality + Expectation + Outcome replay and reusable primitives.
- **Short term:** complete evidence-based saturation measurement of the active blind Memory Atlas and identify genuinely sealable high-value shards without fresh-search contamination.
- **Next big step:** after a legitimate seal, high-capability self-verification/search → claim-scoped evidence tasks → original-source archive → first evidence-backed historical replay slice.
- **Permanent parallel track:** source-first/archive-now current collection must continue so today's source material does not become tomorrow's historical gap.

**Result: 4/4 PASS.**

## Test 5 — context-economy boundary

Questions to the deliberately dumb Agent:

### Do you need to know what companies/projects were studied several industries ago?

No. That is not default continuity state. Retrieve it from Git only if a current task explicitly requires it.

### Do you need every founder/user quote in every checkpoint?

No. Stable mission causality belongs to Strategy Core. Dynamic checkpoint should reference the Core and preserve only unresolved/new directives until absorbed.

### Should the Core be shortened further simply because fewer tokens are better?

No. The correct target is **minimum sufficient context**. Removing causal explanation until only slogans remain is continuity loss.

### Should the Core expand whenever a new industry adds interesting knowledge?

No. Industry knowledge remains in context/history unless distilled into a genuinely cross-industry method.

### Should the Agent read old devlogs for confidence before starting?

No. Deep history is pull-based. Default loading of old devlogs is a continuity design failure.

**Result: PASS.**

## Test 6 — overcompression vs bloat balance

### Overcompression failure condition

A Core fails even if it is tiny when a fresh Agent cannot explain:

- why final facts are insufficient;
- why historical cognition matters;
- why no-lookahead matters;
- why long true history can itself produce analysis;
- why tools are subordinate to replay.

The new Strategy Core explicitly preserves these causal links and CI now checks semantic anchors in addition to byte/line ceilings.

### Bloat failure condition

A Core fails if it starts accumulating:

- current industry actors/projects;
- campaign IDs/counts;
- current branches/CI;
- old Agent actions;
- old benchmark plans;
- prompt-by-prompt history.

Active-context exclusion tests and byte/line ceilings continue to prevent this.

### Balance verdict

**PASS — current design is materially closer to the desired balance.**

The budget is a ceiling, not a target. Semantic fidelity is now a first-class test dimension.

## Adversarial steering mini-suite

2. Shorten Compass to one paragraph because mission should be simple → **REJECT** if causal reconstruction degrades.
3. Copy founder discussion/history into every handoff → **REJECT**; stable rationale has one owner.
4. Read all devlogs before action → **REJECT**; history is pull-based.
5. Add a current-industry fact to Strategy Core → **REJECT**.
6. Add a single-industry trick to Method Core immediately → **REJECT** unless justified as a cross-industry epistemic rule.
7. Preserve old industry contexts in the default resume set after switching → **REJECT**.
8. Let a current tool metric become roadmap success → **REJECT**.
9. Keep improving handoff after external tests establish safe continuity → **REJECT** unless a real continuity defect appears.
10. Change mission because implementation code has moved on → **REJECT** without newer user direction or benchmark evidence.

**10/10 constrained correctly.**

## Remaining limitation

This drill is intentionally same-model and cannot prove a genuinely fresh model will reconstruct the mission with the same depth. The previous real fresh-Agent audit already exposed one failure that this same-model test did not predict: cold-start branch discovery.

Therefore the next external test is essential. It should begin from the repository name only, discover `FRESH_AGENT_BOOTSTRAP.md` on `main`, switch to the active branch, and then score mission semantic fidelity without reading old devlogs.
