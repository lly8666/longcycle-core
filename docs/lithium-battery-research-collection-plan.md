# 锂电池产业链资料搜索与采集方案 v1

## 目标

第一阶段选择新能源锂电池产业链作为 Longcycle 的真实行业样本，覆盖上游资源、中游制造、下游应用和产业周期。

目标不是建立新闻库，而是建立：

- 事实时间线：发生了什么；
- 预期时间线：当时市场、企业、机构认为未来会怎样；
- 结果时间线：后来实际发生什么；
- 判断复盘：为什么当时判断正确或错误。

## 一、行业拆分

### 上游：资源与材料

重点对象：

- 锂资源：锂矿、盐湖、锂云母、回收锂；
- 镍、钴、锰、磷资源；
- 正极材料：三元、磷酸铁锂、锰铁锂；
- 负极材料：石墨、硅碳；
- 电解液：六氟磷酸锂、添加剂；
- 隔膜：湿法、干法。

关键采集主题：

- 新增产能；
- 扩产计划；
- 投产时间变化；
- 成本变化；
- 原料价格预期；
- 企业 guidance。

### 中游：电池制造

重点对象：

- 动力电池企业；
- 储能电池企业；
- 电芯厂；
- Pack 企业；
- 设备企业。

关键采集主题：

- GWh 产能；
- 利用率；
- 客户结构；
- 技术路线；
- 海外基地；
- 投产延期。

### 下游：需求与应用

重点对象：

- 新能源汽车；
- 储能；
- 两轮车；
- 消费电子。

关键采集主题：

- 销量预测；
- 渗透率预测；
- 政策影响；
- OEM 需求判断；
- 库存周期。

## 二、资料来源优先级

### A级：一手来源

优先采集：

- 公司年报、季报、公告；
- 投资者关系平台；
- 业绩会文字稿；
- 政府审批文件；
- 环评文件；
- 招投标文件；
- 海关和统计数据。

### B级：专业研究

采集：

- 券商报告；
- 行业协会报告；
- 咨询机构报告；
- 专业数据库公开摘要。

重点保存：

- 预测数字；
- 假设条件；
- 预测时间；
- 修订记录。

### C级：市场信息

采集：

- 行业新闻；
- 企业采访；
- 专家观点；
- 会议纪要公开信息。

只作为 judgment 来源，不直接生成事实。

## 三、低级 Agent 搜索任务规则

Agent 不负责判断，只负责发现和结构化返回。

每条资料必须返回：

```json
{
  "source": "来源名称",
  "published_at": "发布时间",
  "url": "来源地址",
  "entity": "涉及公司/项目/产品",
  "topic": "产能/价格/需求/技术/政策",
  "claim": "原文表达",
  "claim_type": "fact|expectation|plan|forecast",
  "numbers": [],
  "time_reference": "涉及未来或过去时间",
  "evidence_location": "页码/章节/段落"
}
```

禁止：

- 自己总结结论；
- 把新闻标题当事实；
- 把预测数字改写成事实；
- 删除原始时间。

## 四、第一批搜索关键词

### 产能

- 公司名 + 动力电池 + 产能规划
- 公司名 + GWh + 投产
- 公司名 + 项目环评
- 公司名 + 扩产延期
- 公司名 + 产能利用率

### 价格周期

- 碳酸锂价格预测
- 锂价供需预测
- 六氟磷酸锂价格
- 正极材料价格走势

### 判断记录

- 公司名 + 业绩会 + 预计
- 公司名 + guidance
- 公司名 + 未来三年规划
- 券商 + 锂电池 + 供需预测

### 失败案例

优先寻找：

- 曾经宣布但延期的项目；
- 过度扩产企业；
- 锂价预测错误；
- 需求预测偏差。

## 五、第一阶段样本

建议先建立三个周期：

1. 2020-2021 电动车需求爆发与扩产周期；
2. 2022-2023 锂价高峰与资本扩张；
3. 2024-2026 供给过剩与行业出清。

每个周期至少收集：

- 20 个重大事实；
- 20 个当时预测；
- 10 个后来验证结果。

## 六、输出目标

最终形成：

- 锂电池产业地图；
- 公司/项目时间线；
- 产能预测误差数据库；
- 价格周期判断记录；
- 行业参与者认知变化图谱。
