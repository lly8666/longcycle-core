# 1. 中国银行业的一级结构地图

## 1.1 国家与监管层

Memory Leads：

- 中国人民银行：货币政策、基础货币、准备金、公开市场操作、再贷款/再贴现、利率体系、宏观审慎、支付清算等。
- 银行业监管机构历史上发生过多次机构调整；约 1990s–2020s 期间可能涉及人民银行银行监管职能、银监会、银保监会、国家金融监督管理总局等不同阶段。
- 财政部：国有金融资本、特别国债/注资、政策性安排等可能与大型银行改革相关。
- 中央汇金等国有金融资本平台：大型银行资本补充、股权持有和改革可能相关。
- 国家外汇管理相关体系：外汇流动、结售汇、跨境资金与银行外汇业务。
- 存款保险制度：正式建立的具体时间和覆盖规则后续核验。
- 银行业市场利率定价自律机制：存贷款利率定价约束、利率市场化后行业自律等。

这些机构的准确成立/更名/职责切换日期目前不凭记忆写成事实。

## 1.2 银行类型

### 大型国有商业银行

候选对象包括工商银行、建设银行、农业银行、中国银行、交通银行、邮储银行等。不同银行历史沿革和“大行”统计口径需要按时期核验。

典型特征 Memory Leads：

- 全国性网络；
- 大型央国企与基础设施客户深；
- 低成本存款基础通常较强；
- 政策传导和稳增长信贷投放中具有较高重要性；
- 资本、规模、系统重要性约束更突出；
- 各自在公司、零售、县域、跨境等方面存在差异。

### 全国性股份制商业银行

候选对象包括招商、浦发、中信、民生、兴业、光大、华夏、平安、广发、浙商等，准确名单、历史时期和牌照状态后续核验。

典型特征 Memory Leads：

- 市场化程度和产品创新通常较强；
- 部分银行依赖同业负债、金融市场业务或零售转型；
- 存款基础差异很大；
- 更容易观察到资产负债表扩张模式、同业周期、财富管理和零售转型的差异。

### 城市商业银行

- 由早期城市信用合作体系重组而来的历史线索；
- 地方政府、地方国企、当地民营企业和房地产/城投敞口可能更集中；
- 地域集中带来信息优势，也带来单一区域风险；
- 头部城商行可能跨区域扩张并形成不同于普通地方银行的商业模式。

代表性候选：北京、上海、江苏、南京、宁波、杭州、成都、长沙、重庆、贵阳等银行；具体代表性不能凭记忆直接定论。

### 农村金融机构

可能包括农信社、农村合作银行、农村商业银行、村镇银行等不同制度阶段。

重点线索：

- 县域、三农、小微；
- 地方治理和股权结构差异；
- 改制过程；
- 存款稳定性与区域客户黏性；
- 部分机构资产质量、关联交易和治理风险。

### 政策性银行 / 开发性金融机构

国家开发银行、中国进出口银行、中国农业发展银行等需要与商业银行分开；其资金来源、政策目标、资本约束和风险定价逻辑不同。

### 民营银行、互联网银行及其他新型银行

约 2010s 以后出现的一批新牌照/新模式：互联网获客、线上小微信贷、联合贷/助贷、场景金融等。具体机构、规则与历史节点待核验。

### 外资银行在华机构

在跨境公司、贸易融资、外汇、财富等细分市场可能重要，但在国内存贷款总量中份额有限。不同开放阶段和准入规则需后续查证。

# 2. 银行资产负债表：长期研究的主骨架

## 2.1 资产端

### 贷款

需要长期跟踪：

- 公司贷款；
- 零售贷款；
- 个人住房按揭；
- 信用卡；
- 消费贷；
- 小微贷款；
- 经营贷；
- 制造业贷款；
- 基建相关贷款；
- 房地产开发贷；
- 地方政府融资平台相关融资；
- 票据融资；
- 贸易融资；
- 涉农贷款；
- 绿色金融、科技金融等政策导向分类。

重要问题不是只有余额，而是：新增投向、期限、收益率、抵押物、信用风险、资本占用、是否存在隐性担保预期、客户集中度和行业集中度。

### 金融投资

可能包括：

- 国债；
- 地方政府债；
- 政策性金融债；
- 金融债；
- 企业信用债；
- 同业存单；
- 资产支持证券；
- 基金/资管计划/信托计划等历史上可能出现的非标或穿透后资产；
- 交易账户与银行账户的不同会计分类。

需要注意会计准则变化可能使“同一资产”在不同时期报表分类不可直接比较。

### 同业资产与其他资产

- 存放同业；
- 拆出资金；
- 买入返售；
- 应收款项类投资等历史口径；
- 衍生品；
- 贵金属；
- 固定资产/无形资产等。

## 2.2 负债端

### 客户存款

最核心长期变量之一：

- 公司 / 零售；
- 活期 / 定期；
- 通知、协定、大额存单等产品；
- 保证金存款；
- 结构性存款；
- 财政性/机构性资金；
- 存款平均成本率；
- 新发生存款定价与存量重定价速度。

长期机制线索：低成本活期存款比例往往影响 NIM 和 ROA；居民资产配置、资本市场行情、理财收益、房地产预期和企业现金流可能改变存款结构。

### 同业负债与市场化融资

- 同业存放；
- 拆入资金；
- 卖出回购；
- 同业存单；
- 金融债；
- 二级资本债；
- 永续债；
- 其他资本工具或长期债务。

市场化负债通常比核心存款更敏感，资产负债期限错配和再融资风险需要与流动性一起看。

## 2.3 权益与资本

- 普通股；
- 资本公积；
- 盈余/未分配利润；
- 其他综合收益；
- 优先股、永续债等资本工具的监管资本处理；
- 核心一级资本、一级资本、总资本；
- 风险加权资产；
- 杠杆率。

历史比较必须注意监管规则和资本定义变化。

# 3. 银行是怎么赚钱的

## 3.1 净利息收入

大致可以拆成：

`生息资产规模 × 收益率 - 计息负债规模 × 成本率`

但真正研究要看：

- 资产端重定价速度；
- 负债端重定价速度；
- 贷款结构变化；
- 存款结构变化；
- 市场利率；
- 监管和政策对贷款利率的引导；
- 信贷需求强弱；
- 银行竞争程度。

### NIM / 净息差

是中国银行研究的核心指标之一，但跨银行、跨时期比较必须核对口径。可能受：

- 贷款收益率；
- 债券投资收益率；
- 存款成本；
- 同业负债成本；
- 资产负债结构；
- 期限结构；
- 货币政策和 LPR 等利率体系变化；
- 存量按揭重定价；
- 存款定期化。

## 3.2 非息收入

候选包括：

- 银行卡手续费；
- 结算与清算；
- 托管；
- 代理销售；
- 财富管理；
- 理财；
- 投行/债券承销；
- 外汇；
- 交易收入；
- 投资收益；
- 公允价值变动；
- 保险/基金/证券子公司等综合金融贡献。

“中收”与会计报表非息收入并非一定完全同义，后续必须分口径。

## 3.3 信用成本

银行利润不能只看 NIM：

`经营收入 - 经营费用 - 减值/信用成本 ± 其他项目 → 利润`

因此低 NIM 银行未必低 ROE，高 NIM 也可能被高信用成本吞噬。

关键长期变量：

- 不良生成；
- 核销；
- 清收；
- 拨备计提；
- 拨备覆盖率；
- 信用成本；
- 关注类/逾期；
- 资产分类规则变化。

# 4. 中国银行业约 1990–2026 的历史分段 Memory Leads

以下只用于建立待验证时间地图，年份边界均可能需要调整。

## 4.1 约 1990–1997：专业银行向商业化体系演进、信用扩张与历史包袱积累

可能值得验证的主题：

- 国有专业银行商业化改革；
- 政策性业务与商业性业务逐步分离；
- 地方信用、国企贷款和行政性信贷遗留；
- 早期资产质量问题与资本不足；
- 城市信用社、农村信用社体系；
- 利率高度管制，存贷款利差具有政策性；
- 银行治理和风险定价能力仍在建立。

当时的关键 Judgment 问题可能是：银行究竟是政策财政延伸还是商业化金融机构？坏账到底有多严重？商业化改革会不会真正形成硬约束？

## 4.2 约 1998–2002：亚洲金融危机后、银行体系清理与风险处置

Memory Leads：

- 亚洲金融危机提升对金融体系风险的关注；
- 大型银行不良资产、资本和治理问题可能成为改革重点；
- 资产管理公司承接部分不良资产；
- 财政/政策性资本补充可能发生；
- 监管体系逐渐专业化；
- 国企改革与银行坏账处置相互关联。

后续要核验：不同大行不良剥离规模、AMC 成立时间、资本补充形式、政策目标与实际结果。

## 4.3 约 2003–2007：大行股份制改革、注资、上市与高增长周期

Memory Leads：

- 大型国有银行股份制改造；
- 引入战略投资者、上市；
- 公司治理、风险管理、资本约束改善；
- 中国经济高增长、工业化、城市化和房地产上行带来强信贷需求；
- 银行盈利快速改善；
- 存贷利差和低成本存款可能提供较强盈利支撑；
- 部分股份行形成差异化业务模式。

需验证：各家改革先后、海外/境内上市时间、改革前后 NPL/资本/ROE 的真实轨迹。

## 4.4 约 2008–2012：全球金融危机、强刺激与资产负债表快速扩张

Memory Leads：

- 外部危机后国内宏观刺激；
- 信贷快速投放；
- 基础设施、地方融资平台、房地产等相关融资显著上升；
- 银行资产规模快速增长；
- 后续可能形成产能过剩、地方债务和信用风险遗留；
- 表内贷款约束促使部分融资向表外/非标演化。

需要把“政策驱动的信用扩张”与后来风险暴露严格按时间分开，不能用后来的坏账反写当时所有贷款都明显错误。

## 4.5 约 2010–2013：利率市场化推进、影子银行与非标扩张

Memory Leads：

- 贷款/存款利率管制逐步放开；
- 银行寻找更高收益资产和负债来源；
- 银信合作、理财、信托、非标、同业业务等快速发展；
- 表外资产和期限错配增加；
- 部分银行特别是股份行通过同业和投资账户扩张；
- 监管套利与真实融资需求交织。

重要 Judgment：这些业务究竟是提高直接/间接融资效率，还是把信用风险和流动性风险隐藏起来？

## 4.6 约 2013–2016：同业链条、理财大发展、资产荒与金融加杠杆

Memory Leads：

- 资金市场曾出现明显紧张事件，可能暴露流动性管理问题；
- 同业存单等市场化负债工具发展；
- 理财产品规模扩大；
- 资金通过多层资管产品流向非标、债券或其他资产；
- 经济增速换挡、传统行业信用风险暴露；
- 资产荒/优质高收益资产稀缺可能推动杠杆和久期上升；
- 城商行/股份行之间资产负债模式分化。

## 4.7 约 2017–2019：金融去杠杆、资管新规、影子银行收缩与信用分层

Memory Leads：

- 强监管和金融去杠杆；
- 同业、通道、嵌套和非标受到更强约束；
- 资管新规推动净值化、打破刚兑、期限匹配和穿透监管；
- 部分金融机构负债端和资产端同时承压；
- 民营企业/小微融资问题与信用收缩并存；
- 个别中小银行风险事件强化市场对同业信用和流动性的重新定价；
- 宏观政策可能从去杠杆逐步转向稳杠杆、结构性宽松。

需要后续核验每项监管规则精确发布时间和过渡期，不能凭记忆写死。

## 4.8 约 2020：疫情冲击、政策宽松、让利实体与资产质量担忧

Memory Leads：

- 疫情初期经济冲击；
- 货币与信贷政策偏宽松；
- 延期还本付息、小微支持等政策；
- 银行承担稳增长和让利实体压力；
- 市场担忧延期政策掩盖潜在不良；
- 实际资产质量表现可能与早期悲观预期存在差异，需要分银行、分行业验证；
- 零售和信用卡风险短期上升，随后修复路径不同。

## 4.9 约 2021–2023：房地产下行、城投压力、提前还贷与存款定期化

Memory Leads：

- 房地产行业融资环境收紧后，开发商信用风险加速暴露；
- 银行开发贷、按揭、上下游和债券投资受到不同程度影响；
- 保交楼与政策支持逐步展开；
- 地方财政和城投债务压力受到更多关注；
- 居民风险偏好下降、房地产财富效应减弱、资本市场偏弱等可能推动储蓄增加；
- 理财净值波动可能导致资金回流存款；
- 存款定期化推升部分银行负债成本；
- 存量按揭利率、提前还贷等影响零售资产收益率和规模；
- LPR/政策利率下行及贷款竞争使资产收益率承压；
- 银行净息差进入持续压缩阶段。

## 4.10 约 2024–2026：低利率/低息差环境、负债成本重定价、化债与经营模式再平衡

Memory Leads：

- 银行体系 NIM 可能继续处于较低水平；
- 多轮存款利率调整逐步传导至存量存款，负债成本改善具有滞后；
- 资产端收益率仍受信贷需求、LPR、按揭和优质客户竞争影响；
- 地方债务化解、债务置换可能降低部分资产风险，但也可能压低相关资产收益率；
- 房地产风险从快速暴露转向长期处置/重组阶段的可能性；
- 银行更加重视非息收入、财富管理、交易银行、托管、跨境、科技金融等；
- 资本效率、RWA 管理和精细化定价的重要性上升；
- 行业可能面临“规模仍增、息差下降、信用成本可控但盈利增速弱”的组合；
- 中小银行兼并重组、风险处置与区域分化值得单独建线。

“今天”截止 2026-08-31；本段尤其容易受模型训练资料时点和记忆误差影响，后续必须优先校验。

# 5. 货币政策如何传到银行

## 5.1 准备金与基础货币

研究线索：

- 法定存款准备金率调整；
- 公开市场操作；
- 逆回购；
- 中期借贷便利等工具；
- 再贷款、再贴现；
- 结构性货币政策工具。

需要避免把不同年代不存在或尚未成为主要工具的机制倒推到 1990s。

## 5.2 利率体系

历史上可能经历：

- 存贷款基准利率主导；
- 利率市场化逐步推进；
- 市场利率体系发展；
- LPR 机制改革；
- 政策利率、市场利率、贷款利率传导关系变化。

同一个“降息”在不同时期对银行 NIM 的传导机制可能完全不同。

## 5.3 信贷额度、窗口指导与宏观审慎

中国银行信用创造不应只用欧美式“政策利率→银行放贷”框架理解。历史上可能同时存在：

- 信贷规模指导；
- 窗口指导；
- 差别准备金/宏观审慎考核；
- 房地产贷款集中度等结构性约束；
- 小微、制造、绿色、科技等结构性政策激励。

具体机制和时期必须后验核实。

# 6. 存款：国内银行长期最关键的负债研究线之一

## 6.1 为什么存款重要

- 是银行最主要的低成本、稳定负债来源之一；
- 活期/定期结构影响成本；
- 公司/零售结构影响稳定性和价格敏感度；
- 资金从存款流向理财、基金、股票、房地产，或反向回流，会改变银行负债结构；
- 存款竞争往往在利率下行期决定谁能更快降低成本。

## 6.2 存款定期化机制候选

可能原因：

- 居民风险偏好下降；
- 房地产和权益资产预期变弱；
- 理财收益/净值波动；
- 企业现金管理变化；
- 银行主动产品引导；
- 利率下行预期下居民锁定期限收益；
- 活期支付账户与财富账户迁移。

这些机制可能同时存在，不能看到定期占比上升就直接归因于单一因素。

## 6.3 存款利率下调的滞后

挂牌利率下降并不意味着全量存款成本立刻下降：

- 新发生存款立即受影响；
- 老定期存款到期后才重定价；
- 客户可能改变期限；
- 大额/协议类客户有单独议价；
- 银行竞争会改变实际执行利率。

这是一条值得长期做成 Judgment→Outcome 的机制线。

---

# 7. 房地产与银行

## 7.1 风险链条不能只看开发贷

银行对房地产的可能敞口至少包括：

- 开发贷款；
- 个人按揭；
- 并购贷；
- 房地产企业债券/非标；
- 建筑、材料、家居等上下游企业贷款；
- 以房地产为抵押物的经营贷/公司贷；
- 地方财政土地收入下降对城投和地方国企的间接影响。

## 7.2 开发贷和按揭风险逻辑不同

- 开发贷：项目销售、融资链、企业信用、抵押物、项目所在地均重要；
- 按揭：借款人收入、首付比例、房价、失业、提前还贷、法律执行和社会行为均影响风险；
- 房价下降不自动等于按揭大面积违约；
- 但房地产长期下行可能通过财富效应、交易量、地方财政和企业链条影响银行更广泛业务。

## 7.3 2021 以后重点 Memory Questions

- 哪些银行房地产开发贷占比高但损失较低/较高？为什么？
- 表内贷款与债券/非标哪个先暴露？
- 保交楼、白名单、融资协调机制等政策对风险迁移的真实影响是什么？
- 风险是否从开发商迁移到地方财政、施工方、小微业主和居民资产负债表？

# 8. 地方政府融资平台 / 城投与银行

Memory Leads：

- 地方基础设施建设长期依赖银行信贷、债券、信托等多种融资；
- 地方政府直接举债约束可能推动融资平台发展；
- 土地财政与城投偿债能力相关；
- 隐性担保预期会影响银行风险定价；
- 城投风险更多可能表现为展期、置换、重组、低息化，而不一定以传统企业破产违约方式释放；
- 化债可能降低信用尾部风险，但同时压缩资产收益率；
- 对地方银行而言，城投与当地政府、国企、财政存款和公共资源业务可能高度耦合。

长期需要区分：地方政府债、城投债、平台贷款、地方国企贷款、政府购买服务等不同法律与信用属性。

# 9. 同业、影子银行、理财和资管

## 9.1 为什么会出现影子银行扩张

候选解释：

- 实体融资需求超过表内贷款约束；
- 利率管制和监管资本约束产生套利空间；
- 银行寻找更高收益资产；
- 理财资金寻找收益；
- 信托、券商资管、基金子公司等通道协作；
- 地产、城投等融资主体愿意支付更高成本。

## 9.2 关键产品/结构 Memory Leads

- 银信合作；
- 信托受益权；
- 委托贷款；
- 理财产品；
- 非标债权；
- 同业投资；
- 买入返售；
- 资管计划嵌套；
- 通道业务；
- 同业存单；
- 表外理财到净值化理财。

产品名称和会计/监管定义随年代变化，不能跨期简单统一。

## 9.3 资管新规后的结构变化

Memory Leads：

- 净值化；
- 打破刚兑；
- 非标期限匹配；
- 穿透；
- 理财子公司；
- 银行理财从表外“类存款”心智向真正资管产品迁移。

实际迁移速度、过渡期和各行差异需要 Evidence。

# 10. 零售银行与财富管理

## 10.1 零售转型

约 2000s–2020s，多家银行可能把零售视为降低资本消耗、提高客户黏性和稳定收入的重要方向。

核心变量：

- 零售客户数；
- AUM；
- 财富客户；
- 私行；
- 信用卡；
- 按揭；
- 消费贷；
- 小微经营贷；
- 零售活期存款；
- 财富管理手续费。

## 10.2 招商银行为何适合作为样板 Memory Lead

- 较早形成零售/财富管理标签；
- 活期存款与客户经营关系值得研究；
- 零售 AUM、财富管理、中收和 NIM 之间存在可研究链条；
- 2022–2024 存款定期化与息差压力可与长期零售优势形成对照。

但“最优秀”“领先多少”等评价必须后续用可比数据而不是记忆定论。

## 10.3 零售风险

- 信用卡和消费金融在经济下行时可能先体现失业/收入压力；
- 按揭通常风险特征不同；
- 小微经营贷可能与房地产抵押、企业现金流、区域经济相关；
- 联合贷/互联网获客改变风控与客户来源。

# 11. 公司银行、交易银行与投行业务

候选研究线：

- 传统公司贷款；
- 供应链金融；
- 票据；
- 现金管理；
- 跨境结算；
- 贸易融资；
- 债券承销；
- 银团贷款；

# 12. 资产质量：最容易被错误比较的领域

## 12.1 NPL 不是完整风险

需要同时看：

- 不良率；
- 不良余额；
- 新生成不良；
- 关注类；
- 逾期；
- 逾期 90 天以上与不良的对应关系；
- 核销；
- 清收；
- 重组；
- 拨备覆盖率；
- 贷款拨备率；
- 信用成本。

## 12.2 历史口径变化风险

- 五级分类体系建立和修订；
- 金融资产风险分类规则变化；
- IFRS/中国会计准则下预期信用损失等变化；
- 表外资产纳入和穿透；
- 延期还本付息等政策可能改变风险确认时间。

跨 1990–2026 做序列时，不能把同名 NPL ratio 当成完全同口径。

## 12.3 不良处置方式

- 核销；
- 批量转让；
- AMC；
- 重组；
- 债转股；
- 抵债资产；
- 证券化等。

不同年代可用工具和监管环境不同。

# 13. 资本与银行增长

## 13.1 为什么资本决定扩张

银行资产扩张会消耗资本，尤其高风险权重资产。需要研究：

- 内生利润留存；
- IPO / 增发 / 配股；
- 可转债；
- 优先股；
- 永续债；
- 二级资本债；
- 政府/股东注资。

## 13.2 ROE 拆解思路

候选框架：

`ROE ≈ ROA × 财务杠杆`

而 ROA 受到：

- NIM；
- 非息收入；
- 成本效率；
- 信用成本；
- 税率等。

资本充足率提高可能降低杠杆但增强稳健性；单纯追求 ROE 不能替代风险调整后的判断。

# 14. 流动性与资产负债管理

关键线索：

- 流动性覆盖率；
- 净稳定资金比例；
- 流动性比例等不同监管指标；
- 高流动性资产；
- 同业负债依赖；
- 存款集中度；
- 期限错配；
- 利率风险；
- 银行账簿利率风险；
- 存贷款重定价缺口。

国内银行很少出现类似海外某些银行的公开存款挤兑案例，不意味着流动性不重要；中小银行、同业市场和区域事件可能表现为不同形式。

# 15. 金融科技与渠道变化

## 15.1 电子银行到移动银行

约 1990s–2020s 可能经历：

- 网点与 ATM；
- 电话银行/网上银行；
- 手机银行；
- 第三方支付；
- 超级 App；
- 开放银行/API；
- 数字人民币相关探索。

渠道变化影响：客户获取成本、支付结算收入、活期存款沉淀、数据风控和网点成本。

## 15.2 互联网金融竞争

- 银行与互联网平台从竞争走向助贷/联合贷合作，再进入更严格监管阶段。

具体规则和节点需后续逐条核验。

# 16. 银行类型之间最值得长期比较的差异

## 16.1 大行

可能优势：

- 存款基础；
- 规模；
- 政府/大型企业客户；
- 融资成本；
- 系统重要性。

可能劣势：

- 政策让利责任更强；
- 资产收益率偏低；
- 组织复杂；
- 高基数导致增长慢。

## 16.2 股份行

可能优势：

- 机制灵活；
- 客户和产品创新；
- 财富、同业、金融市场等专业能力。

可能风险：

- 存款基础差异；
- 市场化负债依赖；
- 某些时期激进资产扩张；
- 行业/客户集中。

## 16.3 城商行

可能优势：

- 区域客户关系；
- 地方经济高增长时资产扩张快；
- 本地财政和企业资源。

可能风险：

- 地域集中；
- 地产/城投集中；
- 治理和股东问题；
- 跨区域扩张后风控半径变化。

## 16.4 农商行

可能优势：

- 本地存款和县域客户；
- 三农/小微信息优势。

可能风险：

- 区域经济集中；
- 治理；
- 小微信用风险；
- 人口流出地区长期增长压力。

# 18. 长周期机制库 Memory Leads

## M-01 利率下行 → NIM 压缩

可能链条：

政策/市场利率下降
→ 新发贷款和存量贷款重定价下降
→ 资产收益率下行
→ 存款尤其长期定期存款成本下降滞后
→ NIM 压缩
→ 银行推动存款降成本、资产结构优化、非息收入和成本管理。

## M-02 信贷刺激 → 后续信用成本

宽信用/强刺激
→ 银行快速扩表
→ 基建/地产/周期行业融资扩张
→ 短期经济和利润改善
→ 若现金流未形成或产能过剩
→ 若干年后不良生成/重组/展期。

必须按 vintage 保存“当时为什么合理”与“后来为什么失效”。

## M-03 表内约束 → 表外/非标创新 → 监管收紧

贷款额度/资本/行业限制
→ 融资需求转向信托、理财、同业、资管通道
→ 银行实现类信贷风险暴露但会计/监管位置变化
→ 杠杆、期限错配和穿透复杂度上升
→ 监管统一资管与穿透
→ 表外收缩、回表或信用分层。

## M-04 房地产上行 → 银行受益 → 下行后的多层风险

房地产繁荣
→ 开发贷/按揭/居民财富/土地财政/企业链条共同扩张
→ 银行资产增长、抵押物价值和存款受益
→ 房地产销售与价格转弱
→ 开发商现金流恶化
→ 地方财政、上下游、居民信心受影响
→ 银行风险不仅出现在开发贷。

## M-05 地方财政扩张 → 城投信用 → 化债与收益率再定价

基础设施需求
→ 融资平台加杠杆
→ 土地财政/隐性担保支持
→ 银行认为信用风险较低
→ 地方财政压力上升
→ 展期/置换/化债
→ 尾部信用风险可能下降但资产收益率也下降。

## M-06 居民资产配置 → 存款结构 → 银行负债成本

房地产/股市/基金/理财回报预期变化
→ 居民资金在活期、定期、理财、基金、保险间迁移
→ 银行 AUM 与存款结构改变
→ 存款成本、手续费和流动性同时变化。

## M-07 严监管 → 信用收缩 → 政策再平衡

金融杠杆/套利上升
→ 监管收紧
→ 同业/非标收缩
→ 融资主体信用分层
→ 民企/弱资质主体融资压力
→ 宏观增长承压
→ 政策从去杠杆调整为稳增长/结构性宽松。

## M-08 资本约束 → 业务模式变化

RWA 快速增长
→ 资本充足率下降
→ 再融资或压降高资本消耗资产
→ 发展中间业务、财富、交易银行、轻资本业务
→ ROE 与增长模式变化。

## M-09 科技渠道 → 客户入口 → 存款与中收

线下网点主导
→ 互联网/移动支付兴起
→ 支付入口被分流
→ 银行数字化转型
→ App/财富平台/场景经营
→ 客户活跃、低成本存款、AUM 和手续费重新分配。

## M-10 风险处置不是一次确认，而是一条轨迹

潜在风险
→ 关注/逾期
→ 重组/展期
→ 不良确认
→ 拨备
→ 核销/转让/AMC
→ 回收或损失

任何时期只看最终核销都会丢失当时风险认知演化。

# 20. Judgment Atlas：以后应优先保存“当时怎么想”

每个历史阶段都应找当期管理层、监管、市场的原始判断，而不是后见之明总结。

## 20.1 管理层常见 Judgment 问题

- 未来 NIM 怎么走？何时见底？
- 存款成本什么时候下降？
- 活期率为什么变？
- 贷款需求是真需求还是价格竞争？
- 房地产风险是否可控？
- 城投是否会形成实际信用损失？
- 信用成本是否已经见顶？
- 某行业不良生成会持续几个季度？
- 资本是否足够支撑增长？
- 是否需要再融资？
- 零售/财富转型能否弥补传统利差下降？
- 理财净值化对客户 AUM 和存款有什么影响？
- 金融科技投入多久能转化为效率？
- 监管变化会不会改变业务模式？

## 20.2 监管者 Judgment

- 当时最担心的是通胀、增长、金融风险还是汇率？
- 对银行资本/流动性是否认为充足？
- 为什么某阶段鼓励信贷、下一阶段又抑制杠杆？
- 对房地产、地方债、小微融资的风险权衡是什么？

## 20.3 市场 Judgment

- 银行股折价是因为 NIM、资产质量、资本还是治理？
- 为什么某阶段市场更相信大行，某阶段更偏好股份行/城商行？
- 对房地产和城投的隐含损失预期如何变化？
- 对“高拨备覆盖率是否真实代表低风险”的争论如何变化？

这些都要保留 source-known time，后来结果不能覆盖旧判断。

# 21. Outcome Atlas：哪些后来结果值得与旧 Judgment 对照

- 预测的 NIM 见底时间是否兑现；
- 存款成本是否按预期下降；
- 定期化是否缓解；
- 房地产不良是否按预期暴露；
- 城投是否实际形成损失还是被置换/展期；
- 疫情延期贷款是否形成预期中的大规模坏账；
- 零售转型是否持续改善 ROE；
- 影子银行收缩是否降低风险还是把融资压力转移；
- 资本补充后是否真正支持高质量增长；
- 理财净值化后银行财富收入和存款结构如何变化；
- 数字化是否降低成本收入比或只是增加 IT 支出。

Outcome 必须在后续真实发生并被来源确认后才挂接，不能出现在早期 Judgment 的语义里。
