## Boundary matrix retained from this challenge

| Event family | Primary state change | What it does **not** prove |
| --- | --- | --- |
| de novo entry / institution formation | new license, legal person or permitted business presence | predecessor failure; claimant loss |
| corporatization / conversion | legal/governance/ownership form | market exit; bankruptcy |
| IPO / strategic investment | capital-market/shareholder state | prudential resolution; control by foreign regulator |
| owner recapitalization / asset cleanup | capital or impaired-asset position | license termination; takeover |
| ordinary prudential correction | supervisory constraints on a going concern | formal resolution unless control/exit action is separately shown |
| takeover / suspension / revocation / merger / liquidation / bankruptcy | control, operation, license, entity or court state | uniform claimant outcome |
