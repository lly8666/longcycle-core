# 1. 会计与监管语义：跨 1990–2026 最危险的可比性问题

## 1.1 同一个“贷款”可能不是同一语义

长期序列至少要防：

- 人民币贷款 vs 本外币贷款；
- 集团口径 vs 母行口径；
- 客户贷款及垫款净额 vs 总额；
- 票据融资是否包含在公司贷款；
- 信用卡是否包含在个人消费贷款；
- 小微口径是否按单户授信上限、监管认定或内部分类；
- 房地产贷款是否含个人按揭；
- 平台贷款与一般地方国企贷款的分类变化。

## 1.2 金融投资会计分类变化

不同年代可能出现：

- 交易性金融资产；
- 可供出售金融资产；
- 持有至到期投资；
- 应收款项类投资；
- 以公允价值计量且变动计入损益；
- 以公允价值计量且变动计入其他综合收益；
- 以摊余成本计量。

因此“债券投资规模”“非标投资规模”不能仅靠报表一级科目纵向拼接。

## 1.3 减值规则变化

Memory Leads：

- 早期以已发生损失/贷款分类为主的减值框架；
- 后续预期信用损失（ECL）框架；
- Stage 1/2/3 一类阶段划分可能成为后期重要披露；
- 会计减值与监管不良分类不完全相同。

需要记录：会计准则切换日期、比较期是否重述、集团/母行差异。

## 1.4 手续费与投资收益重分类

财富管理、银行卡、理财、投行、托管、交易业务可能在不同准则下进入：

- 手续费及佣金净收入；
- 投资收益；
- 公允价值变动；
- 其他非息收入。

“中收下降”不能直接等于“财富业务变差”。

## 1.5 NIM 口径

要核验：

- 净息差 vs 净利差；
- 生息资产平均余额算法；
- 日均/季度平均/期初期末平均；
- 年化；
- 集团/母行；
- 是否把某些交易性资产计入生息资产。

长期比较时必须保留来源口径。

# 2. 客户经济学：银行不只是卖贷款

## 2.1 一个公司客户的综合价值

可能来自：

- 贷款利差；
- 结算存款；
- 现金管理；
- 票据；
- 外汇；
- 贸易融资；
- 债券承销；
- 托管；
- 代发工资；
- 企业年金；
- 员工零售客户转化。

因此“低价贷款抢客户”可能是理性综合经营，也可能是恶性价格竞争，需要看综合回报。

## 2.2 一个零售客户的综合价值

可能包括：

- 活期存款；
- 定期存款；
- 信用卡；
- 按揭；
- 消费贷；
- 基金/保险/理财销售；
- 私行；
- 支付结算；
- 客户转介绍和生命周期价值。

AUM 不等于银行表内资产，也不等于收入。

## 2.3 低成本存款护城河是否稳定

候选挑战：

- 移动支付改变资金沉淀；
- 企业现金管理竞争；
- 居民从活期转定期；
- 财富客户资金在产品间迁移；
- 利率下行时客户更关注锁定收益；
- 银行可能通过产品补贴换取存款。

长期要看“结构优势是否永久”，而不是静态标签。

# 3. 资金业务、债券与交易账户

## 3.1 银行为什么持有大量债券

- 流动性储备；
- 配置低风险资产；
- 资本占用较低；
- 信贷需求不足时替代贷款；
- 利率判断；
- 交易和做市；
- 监管指标需要。

## 3.2 债券牛熊周期如何影响银行

可能渠道：

- 配置账户持有到期收益；
- OCI 估值变化；
- 交易收益；
- 债券久期；
- 回购融资；
- 理财产品净值；
- 同业资产负债重定价。

国内银行利率风险与美国式 HTM/AFS 案例不可机械类比，需要看国内存款行为、会计分类、监管和流动性环境。

## 3.3 同业存单

研究问题：

- 哪类银行发行最多；
- 为什么中小银行依赖度高；
- 利率上升/信用分层时再融资成本如何变化；
- 同业存单如何与理财、货基、券商资管形成资金循环。

## 3.4 外汇与跨境

银行跨境业务变量：

- 外币存贷款；
- 结售汇；
- 贸易融资；
- 海外分行；
- 外汇衍生品；
- 跨境人民币；
- 美元利率周期；
- 汇率风险和资本流动。

中国银行等国际化程度高的机构需要单独做集团视角。

# 4. 支付、结算和交易银行

## 4.1 支付体系变化

Memory Leads：

- 银行卡联网；
- 银联；
- 网上银行；
- 第三方支付；
- 二维码支付；
- 手机银行；
- 数字人民币试点。

银行受影响的不只是手续费，还有客户入口和活期沉淀。

## 4.2 对公现金管理

大企业集团资金集中管理可能使银行争夺：

- 主结算行；
- 现金池；
- 跨境资金池；
- 供应链资金；
- 财政/社保/公共事业账户。

这可能解释某些银行公司贷款利率低但存款成本也低。

# 5. 公司治理与股东：中小银行风险的重要来源

## 5.1 股权结构类型

- 中央国资；
- 地方国资；
- 民营产业股东；
- 金融集团；
- 分散上市公众股东；
- 农村信用社/地方法人复杂股权。

## 5.2 典型治理风险 Memory Leads

- 大股东占款；
- 关联贷款；
- 股权代持；
- 一致行动人；
- 董监高受股东控制；
- 风控独立性不足；
- 异地扩张中总部无法识别分支机构风险；
- 规模冲动与短期业绩考核。

## 5.3 为什么地方政府股东既是优势也是风险

优势：

- 政务资源；
- 财政存款；
- 地方国企客户；
- 风险处置支持。

风险：

- 信贷资源可能服务地方政策目标；
- 城投/地方国企集中；
- 市场化治理边界模糊；
- 地方财政恶化时多条风险同时上升。

# 6. 区域经济、人口与银行

## 6.1 区域增长决定地方银行资产质量

要长期跟踪：

- GDP/产业结构；
- 财政收入；
- 土地出让；
- 人口净流入/流出；
- 房价；
- 民营经济活跃度；
- 制造业集群；
- 地方债务。

## 6.2 长三角银行为什么可能表现不同

Memory hypothesis：

- 民营经济和制造业客户多；
- 居民财富高；
- 城市财政强；
- 区域信用环境相对成熟；
- 产生宁波、南京、杭州、江苏、上海等多家较大地方银行。

这只是待验证的结构解释，不能直接说“长三角银行一定更好”。

## 6.3 东北/人口流出地区

候选问题：

- 传统产业；
- 地方财政；
- 人口；
- 房地产；
- 中小银行治理和资产质量是否出现相互强化。

需要避免区域刻板结论，必须用银行与地区数据检验。

# 7. 行业与客户集中度

银行资产质量应按产业链看，而不是只按一级行业标签。

候选高影响行业历史：

- 房地产；
- 建筑；
- 城投/基础设施；
- 钢铁；
- 煤炭；
- 船舶；
- 光伏；
- 地方制造业；
- 批发零售；
- 出口制造；
- 小微服务业；
- 平台互联网；
- 新能源；
- 科技企业。

同一个行业在不同周期可能从高风险变成高景气，不能永久贴标签。

# 8. 银行运营、人力和成本

## 8.1 成本收入比

受：

- 网点；
- 员工；
- IT；
- 营销；
- 规模效应；
- 收入周期。

成本收入比下降可能因为效率提升，也可能只是收入高速增长。

## 8.2 网点逻辑变化

1990s–2000s：物理网点可能是存款和客户覆盖核心。

2010s–2020s：

- 手机银行减少普通交易对网点依赖；
- 高价值财富/企业服务仍需要线下；
- 县域网点可能有独特价值；
- 网点转型为销售和咨询中心。

## 8.3 科技投入

要区分：

- 核心系统；
- 数据仓库；
- 风控模型；
- 手机 App；
- 云/分布式；
- AI；
- 反欺诈；
- 数据治理。

科技支出不能自动等于数字化优势，应该看客户、效率、风险和收入 Outcome。

# 10. 银行估值与资本市场 Judgment

## 10.1 常用估值框架

Memory Leads：

- PB 更常用于银行；
- ROE、增长、资产质量、资本和股息决定 PB；
- PE 在信用成本低谷可能误导；
- 股息率在低增长阶段的重要性上升。

## 10.2 “破净”不等于市场一定错误

市场可能担心：

- 账面净资产质量；
- 隐含信用损失；
- ROE 长期低于资本成本；
- 政策让利；
- 资本摊薄；
- 治理；
- 低增长。

也可能存在过度悲观。Longcycle 应保存当时估值背后的 Judgment，而不是事后简单说市场错了。

## 10.3 不同阶段市场偏好的银行类型

Memory hypothesis：

- 高增长年代可能偏好股份行；
- 零售/财富高景气时偏好招商等；
- 信用担忧上升时可能偏好大行稳健/高股息；
- 区域经济强时头部城商行可能获得溢价。

必须用历史市场资料核验。

# 11. 银行与财政、准财政的边界

长期中国银行研究必须问：

- 哪些贷款纯商业决策？
- 哪些承担稳增长、扶贫/乡村、基建、保交楼、小微等政策目标？
- 政策目标是否有财政补贴、风险分担、再贷款支持？
- 银行“让利”是否通过负债成本/政策工具部分补偿？

不能把所有政策性投放都简单视为低质量，也不能因为有政策支持就假设无风险。

# 12. 银行与保险、证券、基金、信托的综合金融

部分银行集团可能拥有：

- 基金公司；
- 理财子；
- 租赁；
- 信托；
- 保险；
- 券商/投行关联资源；
- 消费金融。

研究银行盈利必须明确是否集团口径，子公司贡献在不同银行差异大。

# 13. 反例库：用来防止形成过度简单的银行规律

## 13.1 高 NIM 不一定是好银行

可能因为：

- 高风险小微信贷；
- 地域弱、客户风险高；
- 高收益资产对应高信用成本。

## 13.2 低 NIM 不一定经营差

可能因为：

- 大量低风险资产；
- 低资本消耗；
- 强非息收入；
- 低信用成本；
- 低资金成本。

## 13.3 高拨备覆盖率不一定等于风险绝对低

可能受：

- 不良认定；
- 核销速度；
- 分母大小；
- 拨备政策；
- 潜在 Stage 2/关注类风险。

## 13.4 存款增长快不一定好

如果：

- 主要是高成本定期；
- 无法配置高收益资产；
- 导致 NIM 稀释。

## 13.5 贷款增长慢不一定差

可能是主动控制风险、缺乏高回报资产或资本优化；也可能是客户竞争力下降。需要 Judgment + Outcome。

## 13.6 房地产敞口低不等于完全免疫地产风险

因为：

- 地方财政；
- 抵押物；
- 上下游；
- 居民财富；
- 城投；
- 小微经营都可能受影响。

## 13.7 大行并非天然低风险

规模、政策任务、复杂度也可能带来风险；只是风险表现和处置机制可能不同。

## 13.8 地方银行高 ROE 可能来自区域红利，也可能隐藏集中风险

需要拉长周期才能判断。

# 14. 重大 Judgment 争议模板

后续任何历史阶段应尝试找当时双方观点：

- 银行不良“真实”还是被延期/隐藏？
- 城投是不是实际政府信用？
- 房价下跌会不会导致按揭违约潮？
- 存款定期化是暂时还是长期？
- NIM 见底主要靠负债重定价还是资产收益率企稳？
- 大行政策性让利是否导致股东回报永久下降？
- 高股息能否抵消低增长？
- 金融科技会不会颠覆银行还是最终成为银行基础设施？
- 资管净值化会不会永久削弱银行理财？
- 小微高收益能否覆盖高信用成本？

保存争议比只保存最终共识更有价值。

# 15. 仍然存在的 negative space

Pass 03 后，模型还能想到但尚未充分展开：

1. 农村金融体系 1990–2026 的完整改革史；
2. 政策性银行与商业银行之间的资金/项目关系；
3. 跨境资本流动、汇改周期和银行外币流动性；
4. 银行欺诈/案件风险历史；
5. 信用卡 2000s–2020s 完整周期；
6. 消费金融公司和联合贷；
7. 银行理财子逐家差异；
8. 绿色金融、科技金融、普惠金融等政策型资产增长的经济性；
9. 银行股分红/资本补充之间的长期平衡；
10. 银行并购重组机制；
11. 主权/地方债占银行资产比例上升后的长期盈利含义；
12. 人口老龄化对存款、按揭、财富管理和网点的长期影响。

这些需要再做一个专题补漏 pass。如果新增内容仍落在现有一级结构，就可接近 seal。
