## 1. 为什么先选这个样板

这个主题比单一信用事件更接近国内商业银行的日常经营主轴：资产端贷款收益率受 LPR、按揭重定价、有效信贷需求和竞争影响，负债端受存款竞争、居民风险偏好和存款定期化影响，两端共同决定净息差。招商银行公开披露较丰富，零售与公司业务兼具，适合先把“当时管理层怎么看息差和存款成本”与后来实际结果分开保存，再扩展到国有大行、股份行和城农商行。

## 2. Actor leads（仅 Memory Leads）

1. 招商银行及其董事会、高级管理层、资产负债管理与财务条线。
2. 招商银行零售客户、企业客户及财富管理客户；居民存款行为可能影响活期/定期结构。
3. 中国人民银行：政策利率、LPR、存款利率市场化调整机制等可能影响资产负债定价。
4. 原银保监会 / 国家金融监督管理总局：资本、流动性、风险管理及商业银行经营监管背景。
5. 银行业市场利率定价自律机制及同行定价行为：可能影响存款挂牌利率和竞争强度。
6. 房贷借款人及按揭市场：存量按揭重定价、提前还款、住房信贷政策可能影响资产端收益率。
7. 同业银行，尤其国有大行与股份制银行：贷款和存款价格竞争的行业参照。
8. 投资者、分析师与评级机构：可作为“市场当时如何理解管理层表述”的后续研究对象，但不能替代银行自身 primary source。

## 3. Metric leads（仅 Memory Leads）

### 息差与收益
- 净息差（NIM）及同比/环比变化。
- 净利息收入。
- 生息资产平均收益率。
- 客户贷款平均收益率；公司贷款、零售贷款、按揭等分项收益率。
- 金融投资收益率或生息资产结构变化。

### 负债与存款
- 客户存款规模与增速。
- 活期 / 定期存款占比及变化。
- 零售 / 公司存款占比。
- 存款平均成本率、计息负债成本率。
- 高成本存款、结构性存款等可能相关的结构指标。
- 存款期限迁移、定期化程度及管理层对其原因的解释。

### 资产负债重定价
- LPR 下调对新发放贷款定价和存量贷款重定价的影响。
- 存量按揭利率调整 / 重定价影响。
- 资产与负债重定价速度差异。
- 存款挂牌利率下调对后续存款成本的滞后影响。
- 贷款需求不足、优质客户竞争对贷款定价的影响。

### 经营缓冲
- 非息收入及财富管理相关收入。
- 成本收入比。
- 贷款结构、零售与公司业务结构。
- 资产质量指标，用于判断息差压力是否同时伴随信用成本变化，但不与 NIM 概念混为一谈。

## 4. Candidate mechanism hypothesis（研究假设，不是事实结论）

一个待验证的国内银行息差周期可能是：

1. 宏观增长与融资需求偏弱、政策引导降低实体融资成本，推动贷款定价和资产收益率下降；
2. LPR 及存量贷款/按揭重定价使资产端收益率较快下行；
3. 居民和企业风险偏好变化、理财净值波动或对确定性收益偏好上升，推动存款增长并出现活期向定期迁移；
4. 存款定期化以及银行间负债竞争令存款成本下降速度慢于资产收益率下降速度；
5. 资产端与负债端重定价存在时间差，净息差因此持续承压；
6. 银行随后通过下调存款挂牌利率、优化存款结构、调整资产结构和客户经营降低负债成本，但改善存在滞后；
7. 管理层对“息差何时见底、存款成本何时改善”的判断，可以作为 Judgment；后续实际 NIM 与存款成本变化作为 Outcome 单独比较。

该链条目前全部属于 Memory-derived research hypothesis，必须逐项用当期来源验证，不能直接发布为 Reality。

## 5. Contemporaneous Judgment leads（仅待查线索）

优先寻找管理层在当时对以下问题的原始判断：

1. **净息差走势**：管理层当时是否判断 NIM 仍有下行压力、何时可能趋稳、主要拖累来自资产端还是负债端。
2. **存款成本**：是否预期挂牌利率下调将在未来几个季度逐步传导，存款成本何时出现改善。
3. **存款定期化**：管理层如何解释活期向定期迁移，是否认为这一趋势会持续、缓解或反转。
4. **贷款收益率**：对新发贷款定价、LPR、按揭重定价和优质客户竞争的判断。
5. **按揭影响**：存量按揭重定价或提前还款对资产收益率、贷款规模及客户行为的预期。
6. **客户资金迁移**：存款、理财、基金、保险等客户资产之间迁移是否影响低成本存款沉淀。
7. **行业竞争**：管理层是否认为存贷款价格竞争将进一步加剧或趋缓。

优先级：先验证一条“管理层对 NIM / 存款成本未来走势”的 dated primary-source Judgment，再扩展机制链。

## 6. Approximate timeline leads（只保留模糊时间精度）

### 2022（约）
- 国内利率和贷款定价环境进一步走低的压力逐渐显现。
- 居民风险偏好、理财市场波动及储蓄行为变化可能推动银行存款增长与定期化。
- 银行开始更明显讨论净息差压力与负债成本管理。

### 2023（约）
- 资产端重定价、贷款市场竞争和按揭相关调整可能继续压低收益率。
- 多轮存款利率调整可能逐步发生，但旧存款到期重定价存在时滞，因此负债成本改善未必同步。
- 管理层对 NIM 低点、存款成本拐点和定期化趋势的判断应当成为重点 PIT Judgment。

### 2024（约）
- 继续观察存款成本改善是否兑现，以及是否足以对冲贷款收益率继续下行。
- 观察 NIM 是否出现趋稳、降幅收窄或仍受新一轮资产重定价拖累。

以上年份内的具体事件、日期、利率幅度和财务数据全部待来源核验。

## 7. Explicit unknowns

当前不能凭记忆确认：

- 2022、2023、2024 各期招商银行准确 NIM、净利息收入、贷款收益率、存款成本率及环比/同比变化。
- 各期活期/定期、零售/公司存款的准确结构和迁移幅度。
- 管理层首次或最明确讨论“存款定期化”的准确日期、原话和上下文。
- 管理层对 NIM 见底或存款成本改善的具体预测时间点。
- 各轮存款挂牌利率调整的准确日期、适用期限和招行执行情况。
- LPR、存量按揭调整和新发贷款定价对招行各期收益率的定量贡献。
- 理财赎回或客户资金迁移对招行存款结构的实际量化影响。
- 同期其他股份行/国有大行的差异是否足以改变“代表性”判断。
- 任何 later-outcome 复盘中对管理层当时观点的概括，是否与当期原始材料一致。

`not_found != false`：后续有限搜索找不到某条信息，只能记录 unresolved，不得把“没找到”写成“没有发生/没有说过”。

## 8. Evidence acceptance boundary

后续只有满足 claim-scoped 来源要求的材料，才可承担 Evidence 权威：

- 招商银行年度报告、半年度报告、季度报告；
- 招商银行官方业绩公告、业绩演示材料、投资者关系活动记录或可识别的管理层公开记录；
- 中国人民银行、金融监管总局等监管机构的官方规则或公告，用于政策/监管事实；
- 对应 claim 必须能定位到具体来源、具体内容和来源可知时间。

不得作为 Evidence 的内容包括：

- 本 Memory packet；
- 模型记忆或模型概括；
- 搜索结果 snippet；
- 未打开核验正文的二手媒体摘要；
- 后来的复盘文章对当时观点的转述。

## 9. PIT / no-lookahead boundary

每条后续 Judgment / Reality 候选至少区分：

1. 事件或财务指标实际对应的 effective period；
2. 原始来源的发布日期 / 市场最早可知时间；
3. Longcycle 采用该信息的时间；
4. 如果是预期，预期针对的未来时间窗口。

严格禁止：

- 用 2024 年或之后的结果反写 2022/2023 年管理层“当时应该知道什么”；
- 用后来年报对前期的总结替代前期原始 Judgment；
- 把实际 NIM 结果和此前 NIM 预测混在同一语义对象中；
- 把模糊记忆中的月份或季度伪精确成具体日期。

## 10. 第一条 post-seal 证据路线

封存后，第一条证据搜索只做一个高信息增益问题：

> 在 2022 年年报 / 2023 年上半年或相邻官方管理层材料中，招商银行管理层当时如何判断未来净息差和/或存款成本走势？

目标不是一次性证明整个机制，而是先得到一条：

- dated；
- primary / source-identifiable；
- content-verified；
- conservative known-time；
- 明确属于当时 Judgment，而不是后来 Outcome 的管理层观点。

然后再把这条 Judgment 与后续实际 NIM / 存款成本 Outcome 分开验证。
