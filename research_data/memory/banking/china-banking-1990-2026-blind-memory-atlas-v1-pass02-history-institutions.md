# 1. 1990s：从行政信用体系向现代商业银行体系迁移的 Memory Leads

## 1.1 专业银行与政策性金融分离

模型记忆中，1990s 前后中国银行体系存在由专业银行承担大量政策性融资的历史背景，随后逐步建立政策性银行并推动国有专业银行商业化。

候选事件 lead：

- 约 1994 年前后，国家开发银行、中国进出口银行、中国农业发展银行等政策性金融机构建立或完成制度化分工；
- 工、农、中、建等大型银行逐步强化商业银行定位；
- 政策性贷款从商业银行资产负债表中剥离/重新安排的过程值得核验。

关键研究问题：

- 政策性业务究竟在何时、以什么方式从大型银行分离？
- 分离后，大行是否真正拥有独立信用风险定价和资本约束？
- 地方政府与国企融资是否仍保留强烈行政色彩？

## 1.2 商业银行法律与监管框架形成

Memory Leads：

- 1990s 中期可能有《商业银行法》等基础法律确立商业银行经营原则；
- 人民银行同时承担中央银行和银行监管重要职能；
- 资产负债比例管理、不良贷款分类、资本监管等现代监管元素逐步建立。

具体法律首次颁布、修订和实际执行时间都待核验。

## 1.3 1997–1999 前后：金融风险治理转折

模型记忆中可能的重要节点：

- 亚洲金融危机使中国更加重视银行不良资产与资本不足；
- 全国金融工作会议一类高层会议可能形成系统性改革部署；
- 大型国有银行获得资本补充；
- 政策上加快不良资产处置和专业化监管。

可能存在的精确数字记忆 lead（高风险，禁止当事实）：

- 1998 前后可能通过特别国债等方式向国有大行补充大规模资本；
- 1999 前后四家金融资产管理公司承接四大行大规模不良资产，模型记忆中常见“约万亿元级”或“约 1.4 万亿元”等说法，但必须查官方历史材料才能使用。

## 1.4 四大 AMC

候选机构：华融、长城、东方、信达。

研究线：

- 分别对应哪些原国有大行；
- 首批政策性不良剥离规模；
- 收购价格是账面价值、折价还是政策定价；
- 资金来源、债券安排；
- AMC 后续从政策性处置平台向商业化金融机构转变的路径；
- 银行早期不良是否真正损失消化，还是在财政/AMC/银行间重新分配。

# 2. 2000–2007：大行重组、股份制改革和上市

## 2.1 监管专业化

模型记忆：约 2003 年前后成立专业银行监管机构（银监会），从人民银行分离主要银行监管职能。

需要核验：

- 正式成立日期；
- 职责边界；
- 监管统计和资本规则如何升级；
- 对股份行、城商行、农信体系的不同改革路径。

## 2.2 中央汇金与大行注资

Memory Leads：

- 约 2003 年以后中央汇金在大型银行改革中扮演重要股东/注资平台角色；
- 中国银行、建设银行可能较早接受外汇储备相关资本注入；
- 工商银行、农业银行之后分阶段重组；
- 不良资产继续剥离、拨备和资本补充同时进行。

应查：每家银行的注资金额、币种、时间、股权结构、不良剥离和财务重述。

## 2.3 战略投资者

2000s 大行上市前引入海外战略投资者是重要 Memory Lead。

候选问题：

- 哪些国际银行/金融机构投资了建行、中行、工行、交行等；
- 交易发生在 IPO 前多久；
- 战略投资者到底带来了治理/风控/技术能力，还是主要是资本与市场背书；
- 后来何时退出、收益如何。

## 2.4 上市时间线候选

模型记忆中大致顺序可能是：

- 交通银行在大型银行中较早完成境外上市；
- 建设银行约 2005；
- 中国银行、工商银行约 2006；
- 农业银行约 2010；
- 邮储银行更晚，先 H 股后 A 股可能是后续阶段。

这些年份和先后必须由招股书/交易所材料核实。

## 2.5 股份行与城商行商业化

这一时期需要盲搜记忆的机构机制：

- 招商银行零售战略、“一卡通”等客户入口的历史意义；
- 浦发、民生、中信、兴业、光大等股份行形成公司/同业/零售差异；
- 北京银行、南京银行、宁波银行等城商行陆续上市或扩大经营半径；
- 城市信用社重组为城商行的历史过程。

# 3. 2008–2012：金融危机后的信用扩张与地方融资

## 3.1 2008 全球危机后的国内刺激

Memory Leads：

- 大规模财政刺激与宽信用；
- 2009 年银行新增贷款可能达到历史高位；
- 基础设施、铁路、公路、城市建设和地产相关融资上升；
- 大型银行作为政策传导主力快速扩表。

注意：常见“4 万亿”记忆是宏观刺激计划标签，不等于银行新增贷款规模，后续必须严格区分。

## 3.2 地方政府融资平台兴起

机制候选：

地方基建任务
→ 地方政府预算/直接举债约束
→ 设立或扩张融资平台
→ 银行以平台、项目公司、土地/财政资源为基础授信
→ 大量长期基础设施资产形成。

后续研究应区分：

- 有经营现金流的城市公用类平台；
- 主要靠财政支持的纯融资平台；
- 土地储备/开发类平台；
- 地方国企与融资平台之间的边界。

## 3.3 房地产与按揭扩张

Memory Leads：

- 城市化、住房商品化和房价上涨推动开发贷和按揭规模增长；
- 按揭逐步成为银行优质零售资产的重要组成；
- 房地产开发商和土地财政与银行公司业务深度关联。

# 4. 2010–2016：利率市场化、同业链条、理财与影子银行

## 4.1 利率市场化时间线候选

模型记忆可能包含：

- 贷款利率下限逐步放宽并最终取消；
- 存款利率上限逐步扩大直至形式上放开；
- 同业和债券市场利率较早市场化；
- LPR 最早版本可能在 2013 左右出现；
- 2019 年又进行了重要改革，使 LPR 更直接与政策利率/MLF 等机制关联。

具体每一步后续必须用人民银行材料核验。

## 4.2 为什么理财和非标扩张

机制记忆：

存款利率受约束 + 居民追求更高收益
→ 银行发行理财
→ 理财资金配置债券/非标
→ 信托、券商、基金子公司等提供通道
→ 融资主体绕过表内信贷约束
→ 银行获得中收/投资收益，同时承担声誉、流动性或隐性信用风险。

需要证据判断哪些风险真正留在银行，哪些法律上在表外。

## 4.3 同业业务

候选工具：

- 买入返售；
- 同业存放；
- 拆借；
- 同业投资；
- 信托受益权/资管计划；
- 同业存单。

部分股份行和城商行可能在这一阶段通过“同业负债 → 投资资产”形成高增长模式。

## 4.4 2013 前后资金市场紧张事件

模型有“钱荒”一类强记忆：

- 银行间市场利率在某段时间急升；
- 暴露流动性、期限错配和同业依赖；
- 人民银行操作与市场沟通成为重要事件。

具体日期、Shibor/回购利率峰值、政策背景都应后续核实。

## 4.5 2014–2016：宽松、资产荒与金融加杠杆

Memory Leads：

- 经济增速放缓后货币环境趋松；
- 债券牛市和较低资金成本；
- 银行、理财和非银机构加杠杆配置债券；
- 高收益资产稀缺导致“资产荒”；
- 同业存单成为部分中小银行重要负债工具；
- 城投、地产、非标和信用债之间资金链复杂。

# 5. 2017–2019：金融去杠杆与统一资管监管

## 5.1 去杠杆政策环境

候选变化：

- 宏观审慎监管强化；
- 同业业务和表外理财受到更严格监管；
- 对监管套利、通道、嵌套、多层资管的打击；
- 银行资产增速下降，部分中小银行缩表或调整资产结构。

## 5.2 资管新规

模型记忆中 2018 左右发布统一资管规则是重大节点。

关键词：

- 打破刚兑；
- 净值化；
- 期限匹配；
- 限制多层嵌套；
- 非标投资约束；
- 穿透监管；
- 过渡期；
- 银行理财子公司。

## 5.3 信用分层与民企融资压力

机制候选：

去杠杆/非标收缩
→ 高风险融资渠道减少
→ 弱资质民企、地产和部分平台融资压力增加
→ 信用债违约和信用利差上升
→ 政策再强调民企、小微融资。

## 5.4 中小银行风险事件池

### 包商银行

强 Memory Lead：约 2019 年被监管接管，成为研究同业信用打破、银行治理、股东关联和中小银行风险处置的重要案例。

需要核验：

- 接管准确日期；
- 风险成因；
- 大股东关联交易；
- 同业负债处置；
- 存款保险基金参与；
- 后续破产/清算与资产负债承接安排。

### 锦州银行

Memory Lead：曾因资产质量、审计/年报延期、资本和股权重组等受到市场关注；后续引入国有资本/AMC 等可能参与重组。

### 恒丰银行

Memory Lead：治理问题、风险处置、资本重组和引入战略投资者等值得形成单独轨迹。

这些个案不能用二手标签替代官方风险处置文件。

# 6. 2020：疫情与银行“让利实体”周期

## 6.1 货币与信用支持

Memory Leads：

- 降准/结构性工具；
- 再贷款再贴现；
- 小微融资支持；
- 延期还本付息；
- 银行降低贷款利率、费用等“让利”要求。

## 6.2 市场当时可能的主要 Judgment

- 延期贷款会不会在政策退出后集中变成 NPL？
- 银行利润是否被让利大幅侵蚀？
- 零售贷款、信用卡和小微风险会不会失控？
- 房地产是否仍能成为信用稳定器？

这类当时判断非常适合以后做 PIT replay。

# 7. 2020–2023：房地产融资约束与信用风险暴露

## 7.1 房地产监管节点候选

模型记忆包括但不限于：

- 房地产企业融资“三道红线”一类约束约在 2020 前后形成；
- 银行房地产贷款集中度管理可能在 2020/2021 前后出台；
- 预售资金监管、保交楼、房企融资支持政策后续持续变化。

所有精确时间和适用对象必须核实。

## 7.2 房企风险事件池

候选：恒大、融创、世茂、碧桂园、旭辉、龙湖等不同类型主体。

研究目的不是做地产公司史，而是看：

- 银行贷款/债券/非标暴露；
- 银行何时开始收紧授信；
- 当时管理层如何描述风险；
- 后来真实不良和损失；
- 抵押物和项目区域差异；
- “开发贷风险可控”判断是否兑现。

## 7.3 保交楼与融资支持

Memory Leads：

- 政策从限制高杠杆逐步转向稳定项目交付和合理融资；
- 银行可能参与专项借款配套、项目白名单等机制；
- 风险分析要从“房企主体信用”转向“项目现金流与交付”。

# 8. 2021–2024：居民资产配置、理财波动与存款定期化

## 8.1 居民储蓄上升机制候选

- 疫情不确定性；
- 房地产预期变化；
- 权益市场表现；
- 理财净值化后波动；
- 消费倾向下降；
- 提前还贷与居民去杠杆；
- 收入预期变化。

不能把“超额储蓄”当单一可直接观测变量，口径需要定义。

## 8.2 2022 前后理财赎回波动

模型记忆中存在债券市场调整导致理财产品净值下跌、居民赎回、形成“赎回—卖债—进一步下跌”反馈的事件。

研究银行影响：

- 理财规模；
- AUM；
- 资金回流存款；
- 存款定期化；
- 财富手续费；
- 理财子流动性管理。

# 9. 2022–2026：净息差成为核心行业矛盾

## 9.1 资产端压力

Memory Leads：

- LPR 和贷款定价下行；
- 优质客户竞争；
- 有效融资需求不足；
- 存量按揭利率调整；
- 新发生按揭利率下降；
- 地方化债和低风险资产收益率下降。

## 9.2 负债端压力与改善

先出现：

- 存款增长较快；
- 活期向定期迁移；
- 存款成本韧性。

随后可能出现：

- 多轮存款挂牌利率下调；
- 协定/通知/高成本存款规范；
- 老存款到期重定价；
- 负债成本逐步下降。

重要问题：负债改善能不能追上资产收益率下降？不同银行为什么差别很大？

# 10. 地方债务与化债周期

## 10.1 早期平台融资

约 2008 以后形成的大量平台债务是长期线索。

## 10.2 2010s 多轮规范

模型记忆中中央可能多次推动：

- 地方政府债务审计；
- 地方政府债券置换；
- 划清政府债与企业债；
- 隐性债务治理。

具体文件和阶段必须查证。

## 10.3 2023–2026 化债

Memory Leads：

- 特殊再融资债等工具可能用于置换部分高成本/隐性债务；
- 银行可能通过贷款展期、降息、置换等方式参与；
- 对银行而言，结果可能是信用风险下降但利差收窄；
- 地方财政存款、政务业务和贷款关系使地方银行的经济利益复杂。

# 11. 中小银行改革与风险处置事件池

除包商/锦州/恒丰外，应后续盲扩：

- 农信社改制农商行；
- 省级农商联合银行/农商联合体改革；
- 村镇银行风险事件；
- 河南村镇银行相关事件是一个强记忆 lead，涉及线上吸储、股东/治理、存款认定与风险处置，具体事实需谨慎核验；
- 辽宁等部分地区中小银行合并重组；
- 山西、四川、河南等地可能有省级城商/农商整合案例；
- 兼并重组、地方国资注资、专项债补资本等工具可能越来越常见。

# 12. 银行监管制度树 Memory Leads

## 12.1 资本监管

可能经历：

- 早期资本充足率要求；
- 巴塞尔 II/III 本地化；
- 《商业银行资本管理办法》不同版本；
- 系统重要性银行附加资本；
- TLAC 相关规则对大型银行的影响。

## 12.2 流动性监管

- 存贷比历史上可能是硬约束，后来弱化/取消监管硬约束属性；
- LCR、NSFR 等逐步引入；
- 同业负债占比、流动性匹配等规则。

## 12.3 资产分类

- 五级分类；
- 逾期 90 天以上与不良认定趋严；
- 金融资产风险分类新规覆盖贷款之外资产；
- 重组资产认定规则变化。

## 12.4 存款保险

模型记忆：制度约在 2015 前后正式实施。

研究点：

- 最高偿付限额；
- 适用存款；
- 保费机制；
- 在包商等风险处置中的实际作用；
- 对隐性担保预期的影响。

# 13. 代表性机构“为什么值得看”扩展

## 13.1 工商银行

代表问题：

- 大型银行改制上市前后的资产质量修复；
- 全球最大规模之一带来的经营效率与资本约束；
- 公司贷款与零售存款；
- 宏观信用周期对大行的传导。

## 13.2 建设银行

- 基建、住房金融历史关联；
- 按揭和房地产周期；

# 14. 典型失败/风险案例池：以后必须保存“当时为什么没看出来”

候选包括：

- 1990s 大行系统性高不良；
- 地方信用社风险与重组；
- 2008 后部分平台/产能过剩贷款风险；
- 2010s 钢铁、煤炭、造船等周期行业不良；
- 同业和非标快速扩张后的流动性风险；
- 包商银行；
- 锦州银行；
- 恒丰银行；
- 河南村镇银行事件；
- 房地产开发商风险暴露；
- 个别银行大股东掏空/关联交易；
- 中小银行跨区域扩张后风控失效案例。

每个案例后续都应该按：

`早期 Reality → 当时 Judgment → 风险信号修订 → 监管/市场动作 → Outcome → hindsight reconciliation`

而不是只保存最终处罚或重组结果。

# 16. Pass 02 saturation check

Pass 02 新增了大量二级结构，但一级主题仍主要落在 Pass 01 已有骨架之内：改革、监管、信用周期、影子银行、地产、城投、机构差异、风险处置。
