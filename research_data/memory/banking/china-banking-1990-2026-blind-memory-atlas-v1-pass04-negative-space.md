# 1. 农村金融体系：不能只用“农商行”一个标签

## 1.1 历史组织形态 Memory Leads

可能经历：

- 农村信用合作社；
- 县级联社；
- 省联社；
- 农村合作银行；
- 农村商业银行；
- 村镇银行；
- 农商联合银行/省级改革新形态。

不同省份改革路径、股权结构和时间差很大。

## 1.2 农信改革的核心矛盾

- 服务三农的政策目标 vs 商业可持续；
- 地方法人治理 vs 省级统一管理；
- 本地信息优势 vs 关联关系风险；
- 高息小微资产 vs 信用成本；
- 县域存款优势 vs 人口流出；
- 地方政府支持 vs 行政干预。

## 1.3 省联社改革研究线

Memory Leads：

- 省联社长期承担管理/服务/行业协调功能；
- 后续一些省份探索改制为农商联合银行、金融控股/服务平台等；
- 核心问题是如何在保持地方法人独立的同时提升科技、风控、资金和治理能力。

精确制度与省份案例待核验。

# 2. 政策性银行、开发性金融与商业银行的接口

政策性银行不能混入商业银行盈利横比，但对整个信用体系非常重要。

## 2.1 可能的功能分工

- 国家开发银行：基础设施、长期项目、开发性金融；
- 农发行：粮食、农业农村等政策领域；
- 进出口银行：出口、贸易和国际合作。

## 2.2 与商业银行的关系

- 银团贷款；
- 联合项目融资；
- 债券作为商业银行投资资产；
- 政策金融债作为流动性/低风险配置；
- 在稳增长阶段承担不同信贷传导角色。

研究时应避免把政策金融债与一般企业信用债风险/资本属性混为一谈。

# 3. 信用卡与消费金融的完整周期 Memory Leads

## 3.1 信用卡扩张

约 2000s–2010s：

- 银行信用卡快速普及；
- 线下商户、分期和消费场景扩张；
- 招行、平安、广发等可能形成较强信用卡标签。

## 3.2 移动支付后的变化

- 支付功能部分被第三方支付替代；
- 信用卡价值更多转向授信、分期、客户经营；
- 获客成本和风险定价重要性上升。

## 3.3 2020s 风险与监管

- 疫情期逾期/不良可能上升；
- 多头借贷、互联网消费金融、现金贷等影响风险；
- 信用卡息费、分期和催收监管趋严可能压缩盈利；
- 银行逐渐更重视存量优质客户而非单纯发卡量。

# 4. 消费金融、互联网贷款、联合贷与助贷

## 4.1 参与者

- 银行；
- 消费金融公司；
- 互联网平台；
- 小贷公司；
- 金融科技风控/获客平台。

## 4.2 商业链条

平台流量/数据
→ 获客和初筛
→ 银行/消金提供资金
→ 联合出资或助贷
→ 风险分担/担保/增信结构
→ 贷后催收。

## 4.3 监管关注

Memory Leads：

- 联合贷出资比例；
- 核心风控不得外包；
- 跨区域互联网贷款；
- 数据和消费者保护；
- 综合融资成本；
- 催收。

具体规则与年代必须后续核实。

# 5. 银行案件、欺诈与操作风险

长期银行史不应只保存信用周期。

## 5.1 可能的案件类型

- 大股东关联交易/掏空；
- 员工违规放贷；
- 虚假贸易背景；
- 票据案件；
- 假存单/存款质押；
- 内外勾结骗贷；
- 理财飞单；
- 数据泄露；
- 电信诈骗资金流；
- 洗钱与制裁合规。

## 5.2 为什么重要

这些事件可能解释：

- 为什么报表资产质量看似正常但最终发生损失；
- 为什么某银行治理折价长期存在；
- 为什么监管强化内控、员工行为和穿透股东管理。

后续应建立代表性案例池，但 blind pass 不尝试列出未经核实的具体案件数字。

# 6. 银行并购、合并与风险重组

## 6.1 可能的历史类型

- 城市信用社合并组建城商行；
- 农信社合并改制农商行；
- 同区域多家银行合并；
- 高风险银行资产负债被健康银行承接；
- 地方国资/AMC 注资；
- 战略投资者进入；
- 股权重组后更名。

## 6.2 研究核心

不能只记录“合并完成”，应追：

`原风险 → 谁先知道 → 监管判断 → 股东损失 → 债权人/存款人处理 → 资本注入 → 不良资产去向 → 新银行经营 Outcome`。

## 6.3 2020s 地方银行整合 Memory Leads

模型记忆中多个省份出现城商行/农商行整合、组建省级法人银行或联合银行的趋势，可能同时服务：

- 化解风险；
- 补充资本；
- 提升治理；
- 统一科技；
- 扩大规模。

应逐案判断，而不是假设所有合并都成功。

# 7. 绿色、普惠、科技、制造等政策型信贷主题

## 7.1 不能只看余额增速

政策鼓励资产可能具有：

- 较低贷款利率；
- 再贷款/风险补偿支持；
- 较低资本或监管激励（需核验）；
- 长期客户价值；
- 政策考核意义。

研究要问综合 ROE，而不是只说“战略方向好”。

## 7.2 绿色金融

候选资产：

- 可再生能源；
- 节能环保；
- 绿色建筑；
- 新能源交通；
- 绿色债券。

可能也存在行业周期风险，例如光伏、风电设备产能等。

## 7.3 科技金融

难点：

- 轻资产、缺抵押；
- 研发周期长；
- 财务利润波动；
- 知识产权估值。

银行可能依赖政府风险分担、投贷联动生态、专营团队或供应链数据。

## 7.4 普惠小微

关键不是简单“多投放”：

- 单户规模；
- 利率；
- 获客成本；
- 风险成本；
- 担保方式；
- 是否依赖抵押；
- 线上/线下风控；
- 批量化能力。

# 8. 跨境、汇率和外币流动性

## 8.1 历史阶段候选

- 1994 左右汇率制度改革记忆；

- 后续人民币国际化、互联互通和跨境金融持续发展。

这些节点必须官方核验。

## 8.2 对银行的影响

- 外币存款成本；
- 美元贷款；
- 海外债券；
- 贸易融资；
- 结售汇手续费；
- 汇兑损益；
- 外币流动性；
- 海外分行信用风险。

# 9. 主权债、地方债与银行资产结构变化

## 9.1 为什么可能越来越重要

当信贷需求弱、地方隐性债务转为显性债务、低风险资产需求上升时，银行可能配置更多：

- 国债；
- 地方政府债；
- 政策性金融债。

## 9.2 对盈利和资本的影响

可能：

- 信用风险较低；
- 资本占用较低；
- 收益率也较低；
- 久期更长；
- 对利率变化敏感；
- 支撑流动性监管指标。

长期可能形成“风险下降但 ROA/NIM 下降”的结构变化。

# 10. 分红、资本补充与股东回报

银行有一个长期张力：

利润
→ 分红给股东
或
→ 留存补资本支撑资产增长。

研究线：

- 大行高分红；
- 快速增长银行资本补充频繁；
- 可转债、配股、定增、优先股、永续债；
- 资本新规改变 RWA 后资本需求；
- 市场对融资摊薄的 Judgment。

# 11. 人口与长期结构

## 11.1 老龄化

可能影响：

- 储蓄率；
- 财富管理；
- 保险；
- 按揭需求；
- 消费信贷；
- 银行网点服务需求。

方向并不简单：老龄化可能增加存款，也可能在退休阶段消耗储蓄。

## 11.2 人口流动

人口流入城市：

- 按揭、消费、企业活动和财政可能更强；
- 地方银行获得增长红利。

人口流出地区：

- 信贷需求不足；
- 房地产和地方财政压力；
- 网点成本较高。

## 11.3 城市化阶段变化

1990s–2010s 高速城市化可能持续推升：

- 基建；
- 房地产；
- 按揭；
- 居民金融资产。

进入成熟阶段后，银行需要从“资产规模增长”转向“存量客户经营和资本效率”。

# 12. 银行业竞争结构

## 12.1 从牌照/网点竞争到综合能力竞争

可能经历：

1990s：牌照、网点、行政客户关系
→ 2000s：全国扩张、信用卡和零售
→ 2010s：同业、理财、互联网、资产扩张
→ 2020s：低息差、客户综合经营、财富、科技、资本效率。

## 12.2 同质化问题

如果所有银行都追求：

- 大型央企；
- 制造业龙头；
- 科技企业；
- 高净值客户；
- 政府项目，

则优质资产价格竞争会进一步压低收益率。

# 13. 宏观 regime 对银行的不同组合

可把历史按四个变量组合看：

1. 名义经济增长；
2. 信用需求；
3. 利率水平；
4. 信用成本。

候选 regime：

- 高增长 + 高信用需求 + 较高利差 + 低信用成本：银行黄金期；
- 宽信用 + 快扩表 + 风险后置：短期利润好、长期不良上升；
- 低增长 + 低利率 + 低信用成本：规模增长但 NIM/ROE 下行；
- 低增长 + 高信用成本：最差组合；
- 去杠杆 + 市场利率高：同业依赖银行压力大。

后续可把每家银行的历史年度映射到 regime，但必须使用真实数据。

# 14. “中国银行业特殊性”假设清单

这些都只是待验证的研究假设：

- 国家在银行体系中股权和政策影响较强；
- 银行是宏观政策传导的重要工具；
- 地方政府与银行资产负债表联系深；
- 居民高储蓄率长期支撑存款；
- 直接融资发展仍未完全替代银行间接融资；
- 隐性担保和风险处置方式影响信用定价；
- 银行危机更多可能通过重组、注资和行政协调化解，而不是公开存款人损失；
- 因此信用风险可能表现为低利率展期、资本侵蚀、盈利下降，而不仅是 NPL 暴增。

每条都需要反例检查，不能把“特殊性”变成万能解释。
