# Handoff rehearsals

This directory contains continuity drill reports. Reports are observations, not authority for project truth.

- Same-Agent artificial-ignorance rehearsals may test whether bounded repository inputs are sufficient, but they must state that they do not prove fresh-Agent independence.
- External fresh-Agent reports must follow `docs/development/fresh-agent-continuity-drill.md` and must not read earlier reports before completing their own scenarios.
- A report may advance the live branch by one report-only commit while recording the pre-report `subject_head` it actually tested.
- Do not copy report conclusions into Method Core, Capability Registry or Repair Memory unless a later maintainer independently verifies a repeated architectural lesson.
